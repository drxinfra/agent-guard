# agent-guard

[English version](README.md)

Защита для ИИ-агентов на настоящих серверах. Плагин Claude Code от [drxinfra](https://drxinfra.ru/agent-guard.html), не привязан к стеку:

- **Спрашивает перед изменениями.** Перед командой, которая меняет систему, Claude Code показывает её с причиной и выполняет только после согласия человека, даже в автоматическом режиме. Форматирование дисков и `rm -rf /` запрещены.
- **Прячет секреты.** Пароли, токены, ключи, строки подключения и учётки в адресах заменяются на `‹hidden›` в выводе Bash, Read и Grep до того, как его увидит модель.
- **Ведёт журнал.** Каждая команда Bash, которую выполнил агент, пишется в журнал JSON Lines (команда с замаскированными секретами, вывод никогда).
- **Скил.** Объясняет агенту, как работать под защитой: где выполнится, что изменит, как откатить; маски и подтверждения не обходить.

## Установка

```
/plugin marketplace add drxinfra/agent-guard
/plugin install agent-guard@agent-guard
```

Нужен `python3` (3.6+) в `PATH`. Зависимостей нет.

## Профили и переключатели

| Переменная | Значения |
|---|---|
| `AGENT_GUARD_PROFILE` | `prod` (по умолчанию): спрашивать перед любым изменением; `test`: только перед разрушительными (delete, drop, destroy, prune, purge, flush, `rm -r` в системных и домашних путях, `terraform destroy`, `git push --force`); `off` |
| `AGENT_GUARD_MASK` | `off` выключает маскировку |
| `AGENT_GUARD_JOURNAL` | `off` выключает журнал |

Запрет (`mkfs`, `wipefs`, `dd of=/dev/sdX`, `rm -rf /`, fork-бомба) одинаков в `prod` и `test`.

Переменные задаются в окружении или в блоке `env` настроек Claude Code. Для одного проекта положите в корень файл `.agent-guard` (ищется от рабочего каталога вверх), он сильнее переменных:

```
profile=test
mask=on
journal=off
```

Правку `.agent-guard` агентом хук всегда выносит на подтверждение.

Что именно спрашивается, по областям (службы, контейнеры, Kubernetes, Terraform/OpenTofu/Pulumi/Ansible, облачные CLI aws/yc/gcloud/az, базы и Redis/MongoDB, RabbitMQ, HTTP, git, хост), смотрите таблицу в [README.md](README.md) и правила в [hooks/guard.py](hooks/guard.py).

## Журнал

`${CLAUDE_PLUGIN_DATA}/journal.jsonl` (если переменной нет, `~/.local/state/agent-guard/journal.jsonl`), строка на команду: время UTC, сессия, рабочий каталог, хост, профиль, команда с масками, код выхода и признак прерывания, если Claude Code их передал, признак сбоя и спрашивал ли хук. Ротация на 10 МБ (хранится один старый файл), права 0600.

```
python3 hooks/journal.py --since 1h
python3 hooks/journal.py --grep kubectl --asked
python3 hooks/journal.py --failed --last 20 --json
```

## Ограничения

- Только Claude Code: хуки работают по его протоколу PreToolUse/PostToolUse.
- Нужен `python3` в `PATH`, без него хуки не срабатывают.
- Это шаблоны, а не песочница: необычно записанную команду (скрипт в файле, `eval`, base64, алиас) проверка может пропустить. Давайте агенту минимальные права и держите резервные копии.
- В режиме `--dangerously-skip-permissions` (bypassPermissions) не полагайтесь на подтверждение.
- Маскировка действует на то, что уходит модели; если в организации включён экспорт телеметрии Claude Code, исходный вывод может попасть туда.
- В журнал попадают завершённые команды; запрещённые и отклонённые на подтверждении не пишутся.
